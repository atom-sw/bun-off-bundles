# Delegate deliberately

A subagent pays for itself when it reads a lot and reports back a little. It loses when it
has to rediscover what you already know: it starts cold, with none of this conversation.

- Delegate a search that will span more than about three files to answer one question, or
  a verbose run you need only a verdict from.
- Ask for findings and the references you would need next, never for file contents.
- Hand over the paths, names, and constraints you already hold, so the subagent spends its
  context on the question instead of rebuilding yours.
- Do the work yourself when the change is targeted, when it needs back-and-forth, or when
  the answer is two or three reads away.
