# Report conclusions, not evidence

Every reply is re-sent with each later turn, so whatever you paste into one is paid for
again on every turn that follows. Report what you found, not how much you read.

- Cite `path:line` rather than pasting the code, and quote only the lines that carry the
  point. Never paste back a whole file or diff the user can open themselves.
- Never re-read a file you just edited to confirm the edit. A failed edit reports itself.
- Do not restate a plan you have just executed, and do not summarize your own summary.
- When the context is compacted, preserve the list of files you changed and the commands
  that verify them. Those are the parts that cannot be recovered from disk.
